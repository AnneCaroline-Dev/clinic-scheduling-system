# Sistema de Agendamento para Clínica Médica

## Sobre o Projeto

Este projeto foi desenvolvido como estudo de Product Discovery, Engenharia de Requisitos, UX Design e Desenvolvimento Front-end.

O objetivo é demonstrar o processo completo de concepção de um produto digital, desde a identificação do problema de negócio até a construção de um MVP funcional.

---

## Problema de Negócio

A clínica realiza seus agendamentos através de telefone e WhatsApp.

Esse processo gera:

* Sobrecarga operacional da recepção;
* Retrabalho em consultas de disponibilidade;
* Longo tempo de espera para atendimento;
* Dificuldade para cancelamentos e reagendamentos;
* Horários ociosos devido a faltas ou desistências.

---

## Solução Proposta

Desenvolvimento de uma plataforma de autoatendimento para pacientes, permitindo:

* Agendamento de consultas;
* Visualização de consultas agendadas;
* Cancelamento de consultas;
* Reagendamento de consultas;

sem necessidade de contato com a recepção.

---

## Visão do Produto

Para pacientes que desejam gerenciar consultas médicas de forma rápida e independente, o Sistema de Agendamento para Clínica Médica é uma plataforma de autoatendimento que permite agendar, cancelar e reagendar consultas de maneira simples e intuitiva.

Diferente do processo tradicional realizado por telefone ou WhatsApp, o sistema oferece autonomia, praticidade e disponibilidade a qualquer momento.

---

## MVP

### Funcionalidades Implementadas

* Login simplificado
* Visualização de médicos
* Visualização de horários disponíveis
* Agendamento de consultas
* Visualização de consultas agendadas
* Cancelamento de consultas
* Reagendamento de consultas
* Feedback de sucesso e erro

### Fora do Escopo

* Telemedicina
* Pagamentos online
* Prontuário eletrônico
* Painel administrativo
* Gestão financeira
* Integração com WhatsApp
