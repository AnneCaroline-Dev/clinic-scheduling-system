# Sistema de Agendamento para Clínica Médica

## Visão Geral

Este projeto foi desenvolvido como estudo de Product Discovery, Análise de Requisitos, UX e Desenvolvimento Front-end.

O sistema tem como objetivo permitir que pacientes realizem o gerenciamento de consultas de forma autônoma, reduzindo a dependência da recepção da clínica.

## Problema

A clínica realiza seus agendamentos por telefone e WhatsApp, gerando:

- Sobrecarga da recepção;
- Retrabalho operacional;
- Longo tempo de espera para atendimento;
- Dificuldade para cancelamentos e reagendamentos;
- Horários ociosos devido a faltas.

## Solução

Desenvolvimento de um portal de autoatendimento para pacientes com funcionalidades de:

- Agendamento;
- Visualização;
- Cancelamento;
- Reagendamento de consultas.
