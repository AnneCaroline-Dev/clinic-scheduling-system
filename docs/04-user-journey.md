# Jornada Atual

1. Preciso marcar uma consulta.
2. Procuro telefone da clínica.
3. Entro em contato.
4. Aguardo atendimento.
5. Recebo opções de horário.
6. Escolho um horário.
7. Consulta é agendada.

Pontos de Dor

- Tempo de espera.
- Dependência da recepção.
- Processo lento.

Jornada Futura

1. Acesso o sistema.
2. Escolho médico.
3. Escolho horário.
4. Confirmo agendamento.
5. Consulta criada.

Resultado

Processo mais rápido e autônomo.
