# 11 - User Stories

## Objetivo

Este documento apresenta as User Stories do MVP utilizando o formato:

**Como [persona], quero [objetivo], para [benefício].**

---

# Epic 1 - Acesso ao Sistema

## US01 - Realizar Login

Como paciente

Quero acessar o sistema

Para gerenciar minhas consultas médicas.

### Prioridade

Must Have

---

# Epic 2 - Agendamento de Consultas

## US02 - Visualizar Médicos

Como paciente

Quero visualizar os médicos disponíveis

Para escolher o profissional desejado.

### Prioridade

Must Have

---

## US03 - Visualizar Horários Disponíveis

Como paciente

Quero visualizar os horários disponíveis de um médico

Para escolher o melhor horário para minha consulta.

### Prioridade

Must Have

---

## US04 - Agendar Consulta

Como paciente

Quero agendar uma consulta

Para reservar um horário com o médico escolhido.

### Prioridade

Must Have

---

# Epic 3 - Gerenciamento de Consultas

## US05 - Visualizar Consultas Agendadas

Como paciente

Quero visualizar minhas consultas agendadas

Para acompanhar meus compromissos médicos.

### Prioridade

Must Have

---

## US06 - Cancelar Consulta

Como paciente

Quero cancelar uma consulta agendada

Para liberar o horário caso eu não possa comparecer.

### Prioridade

Must Have

---

## US07 - Reagendar Consulta

Como paciente

Quero alterar a data ou horário de uma consulta

Para adequar o atendimento à minha disponibilidade.

### Prioridade

Must Have

---

# Epic 4 - Feedback ao Usuário

## US08 - Receber Confirmação de Agendamento

Como paciente

Quero receber uma confirmação após agendar uma consulta

Para ter certeza de que a operação foi realizada com sucesso.

### Prioridade

Must Have

---

## US09 - Receber Mensagens de Erro

Como paciente

Quero visualizar mensagens de erro claras

Para entender quando uma operação não puder ser concluída.

### Prioridade

Must Have
